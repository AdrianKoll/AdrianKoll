## 🔥 Projetos principais

> Sistemas desenvolvidos para resolver problemas reais

### 🚀 ServiceFlow

Sistema web de gestão operacional para organizar serviços, equipe, tarefas e fluxo financeiro.

✔️ Centraliza operações do negócio  
✔️ Organiza serviços, clientes e equipe  
✔️ Reduz retrabalho manual  

---

### 💰 CashFlow / CFC Flow

Sistema para controle de caixa, entradas, saídas, saldo e relatórios financeiros.

✔️ Melhora a organização financeira  
✔️ Facilita o acompanhamento de lucros e despesas  
✔️ Apoia decisões com indicadores visuais  

---

### 🚗 Vehicle Access Manager

Sistema para registro e consulta de acesso de veículos.

✔️ Automatiza registros de placas  
✔️ Agiliza controle de entrada e saída  
✔️ Reduz anotações manuais repetitivas  

---

### 📦 Inventory Manager V2

Sistema desktop para gestão de estoque, produtos e movimentações.

✔️ Organiza produtos e registros  
✔️ Controla movimentações de estoque  
✔️ Estruturado com MVC/DAO e SQLite
