## 🔥 Projetos principais

> Explore abaixo alguns sistemas desenvolvidos para uso real

### 🚀 ServiceFlow
Sistema web de gestão operacional que organiza serviços, equipe e fluxo financeiro.

✔️ Centraliza operações do negócio  
✔️ Dashboard com visão completa  
✔️ Reduz retrabalho manual  

---

### 💰 CashFlow / CFC Flow
Sistema para controle de caixa, entradas, saídas e relatórios financeiros.

✔️ Organização financeira simples e eficiente  
✔️ Visualização clara de lucros e despesas  

---

### 🚗 Vehicle Access Manager
Sistema de automação para registro e consulta de acesso de veículos.

✔️ Reduz anotações manuais  
✔️ Agiliza controle de entrada/saída  

---

### 📦 Inventory Manager V2
Sistema desktop para gestão de estoque.

✔️ Controle de produtos e movimentações  
✔️ Organização e rastreabilidade
